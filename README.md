# Go language examples

Developer: Hamdy Abou El Anein  
Contact: hamdy.aea@protonmail.com

Three independent introductory Go examples are stored in this repository. Each declares its own `main` function, so run the files individually rather than building the entire directory:

```sh
go run hello-world.go
go run Variables.go
go run if-else.go
```

Expected output from `hello-world.go` is `hello world`. The other programs demonstrate variable declarations and conditional branches. Use `go fmt` and `go vet` on each file independently. The pre-existing `hello-world` executable is not required to run the source examples.
